# --- semantic asset relevance and sentiment (shared by every scraper) ---
# Nothing is translated anywhere in this pipeline; every record is analysed
# in its own language, so there is no translation model here any more.

# is skipped entirely for non-Latin text.
# SENTIMENT_MODEL (ProsusAI/finbert) scores English records, and
# MULTILINGUAL_SENTIMENT_MODEL (cardiffnlp/twitter-xlm-roberta-base-sentiment)
# scores every other language, Persian included.
# All are transformers models, downloaded on first use and cached by
# huggingface_hub -- no extra packages beyond what's already here. Every model
# name is overridable from .env (see .env.example) if a machine cannot hold
# the defaults.
